# Танковая арена

Турнир один на один между танками, которые целиком создают нейросети: имя, девиз, внешний вид, характеристики и искусственный интеллект. Сделана для ролика «Opus 5.5 против GPT-6 Astra».

Зависимостей нет, нужен только Node.js 18+.

## Как провести бой

1. Создай папку каждому участнику. Это копия `kit/` с отдельным git, чтобы модели работали независимо друг от друга.

   ```
   node new-contestant.mjs opus  --model "Claude Opus 5.5" --color "#e8825a"
   node new-contestant.mjs astra --model "GPT-6 Astra"     --color "#4fc3c9"
   ```

2. Запусти агента в его папке (`contestants/opus` — Claude Code, `contestants/astra` — Codex) и дай промпт из [prompts/tank-battle.md](prompts/tank-battle.md), одинаковый для обоих.

3. Когда оба закончат, запусти просмотрщик и открой http://localhost:4747:

   ```
   node serve.mjs
   ```

   «Представление и бой» показывает карточки танков, затем матч до нужного числа побед. После матча `T` запускает турнир на скорости (по умолчанию 100 раундов), статистика по картам — в конце.

Быстрый старт по ссылке: `http://localhost:4747/?a=contestants/opus&b=contestants/astra&first=4&auto=intro`.

Клавиши: пробел — старт/пауза, `1`/`2`/`3`/`0` — скорость ×1/×2/×4/×0.5, `M` — звук, `F` — полный экран, `D` — ошибки и пропуски ботов, `Esc` — меню.

## Устройство

- `kit/arena/engine.js` — правила и физика, детерминированные и без DOM. Судья и песочница используют один и тот же код: результат раунда в браузере совпадает с `cli.mjs`.
- `kit/ARENA.md` — правила для участника, `kit/arena/cli.mjs` — песочница, `kit/arena/sparring/` — спарринг-боты «Охотник» и «Манекен».
- `viewer/` — просмотрщик. Каждый бот работает в отдельном Web Worker: он не может трогать движок, соперника или страницу. Ход дольше 50 мс пропускается (танк повторяет прошлую команду), примерно 3 секунды без ответа — бот отключается, матч продолжается.
- Карты симметричны относительно центра, стороны чередуются: каждая карта играется с обеих сторон. Зеркальный матч «Охотник против Охотника» даёт ровно поровну.

Проверка правил без браузера: `npm run sandbox`.
